## Lectura (Claude)

Dos corridas el mismo día: `2026-11-01-sonda.md` con iOS (y Desktop con la misma cuenta) y `2026-11-01-sonda-2.md` con un Android viejo en Telegram X, otra cuenta. Checklist llenado con lo que Jose vio en cada cliente.

**Temas = chats: pasa.** El modo temas responde (`has_topics_enabled`, `allows_users_to_create_topics`), el bot crea temas (`createForumTopic`) y en iOS escribir fuera de un tema **crea un tema implícito** (`forum_topic_created.is_name_implicit: true`, nombrado con los primeros caracteres del mensaje: "Este es un mensa"). La propia app de iOS ya lo presenta como "Nuevo chat" / "Continuar último hilo" / "Escribe cualquier mensaje para crear un nuevo hilo": la interfaz nativa coincide con el modelo, no hay que enseñarlo.

**Hallazgos que cambian el diseño:**

1. **Telegram X (cliente viejo) no tiene temas, ni drafts, ni rich.** Sus mensajes llegan **sin `message_thread_id`** y ve todo revuelto en un solo chat. Un mensaje sin tema solo viene de un cliente así (iOS crea el implícito), así que la regla es: **sin tema → el último chat de Telegram de ese creator, con `/nuevo` para empezar otro.** No "un chat por mensaje".
2. **El rich message rompe en clientes viejos** ("Mensaje no compatible", pasos 8 y 11), y la API no dice qué cliente usa cada quien. **Decisión de Jose: la respuesta final va en HTML** (texto plano, HTML con blockquote plegable y foto con inline keyboard se vieron en los tres clientes). Las tablas chicas, en `<pre>` alineado; las anchas, como lista. Los temas y el draft se quedan: donde no existen, simplemente no aparecen.
3. **iOS no aplica `editForumTopic`** en chats con bots: la API responde `true`, Desktop muestra el nombre nuevo (segunda prueba: tema implícito y tema del bot), iOS se queda con el viejo aunque se cierre la app y se reinicie el teléfono. Limitación del cliente; el autotítulo se manda igual (Desktop y la web sí lo muestran) y se anota.
4. **Drafts:** el de texto, 28 de 28 sin fallos. El rich falló 3 de 39: un `429 retry after 3` por mandar cada 350 ms, y dos `RICH_MESSAGE_CONTENT_REQUIRED` cuando el corte caía dentro de un `<details>` abierto. Para el canal: espaciar los drafts (~1 por segundo) y no mandar un parcial con una etiqueta abierta.
5. **Detener funciona** donde hay drafts: llegó `stopped_message_generation` con el `draft_id` (iOS). En Telegram X no hay botón.
6. **`deleteForumTopic` borra los mensajes del bot de ese tema**, también en la vista sin temas de Telegram X. El bot nunca borra temas.
7. Formas para los PRs de audio y adjuntos: la nota de voz llega como `voice` con `duration` y `mime_type: audio/ogg` (12 s pesaron 50 KB, muy lejos del tope de 20 MB de `getFile`) y el álbum como varios `message` con el mismo `media_group_id`, uno por foto, con el caption en el primero.
